Starter templates

Three starters ship inside the binary — no fetching, no discovery paths. dogbed template <name> prints one to stdout so you copy it and own it. --list (or a bare dogbed template) shows the names:

$ dogbed template --list
verdict	PR review verdict: blockers, nits, summary.
release-notes	Release notes: highlights, breaking, added, changed, fixed.
reading-note	Reading note: author, rating, quote, notes.

The three starters

verdict — a PR review verdict: blockers, nits, summary. Example data in share/verdict.json.

release-notes — release notes: highlights, breaking changes, added, changed, fixed, a changelog link. Every section is guarded with {% if %} — empty data makes the section disappear.

reading-note — a reading note: author, source link, rating, quote, notes. Everything but the title is optional.

The round trip

The whole round trip — print a starter, render it with the document shell:

$ dogbed template release-notes > release-notes.knap
$ dogbed render release-notes.knap -d share/release-notes.json --title 'dogbed 0.2.0' --css style.css
